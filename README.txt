MARY'S THREE-PAGE PORTFOLIO

FILES
- index.html: Home page
- about.html: About page
- projects.html: Projects and contact form
- css/style.css: Website styles
- js/main.js: Small navigation and year updates
- images/profile.jpg: Add your own real photograph here

BEFORE SUBMITTING
1. Add a real photo named profile.jpg inside the images folder.
2. Replace YOUR-GITHUB-USERNAME in all HTML files with your GitHub username.
3. Replace YOUR-TACO-SHOP-REPOSITORY with the actual Taco Shop repository name.
4. Add a real social media profile link on about.html.
5. Edit the biography and skills so they accurately describe you.
6. Update the Taco Shop description with the features you actually built and what you learned.
7. Test all three pages on a phone and computer.

IMPORTANT
The contact form is currently a front-end demonstration. It will not send messages until connected to a form service.
